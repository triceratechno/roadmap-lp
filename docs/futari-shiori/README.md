# ふたりのしおり — 復旧メモ

このフォルダは `futari-shiori` アプリの資料の**一時避難先**です。
専用リポジトリを作ったら、そちらへ移します（この roadmap-lp とは無関係な内容のため）。

## 収録物

- `app-textbook.md` — アプリ設計をまとめた教科書（ユーザー提供）

## 経緯

- アプリは Cloudflare Pages の `futari-shiori` プロジェクトとして公開済み
- ソースは **どの GitHub リポジトリにもコミットされていなかった**
  （開発セッションのコンテナ内に未コミット状態で存在したまま、コンテナが到達不能になった）
- 公開中の `index.html` はブラウザ保存で回収済み
- `app.js` は文字化けした状態でのみ入手（再取得が必要）
- サーバー側（Pages Functions）は未回収

## 未解決：2つの異なるアプリが存在する

`app-textbook.md` が説明するアプリと、`futari-shiori.pages.dev` で現在動いているアプリは**別物**。

|  | 教科書が説明するアプリ | 公開中のアプリ |
|---|---|---|
| 構成 | React + TypeScript + Vite（ビルドあり） | 素の JavaScript 単一ファイル |
| タブ | 日程 / 今日 / 持ち物 / 情報 / メモ / 候補 | プラン / 行きたい / 思い出 / きろく / よてい |
| API | `/api/posts`（GET/POST/PATCH/DELETE） | `/api/data`（GET/PUT/DELETE） |
| 保存先 | D1（`posts` テーブル） | サーバー保存 + localStorage `shioriData` |
| 識別 | `APP_PASSPHRASE`（サイト全体のゲート） | `coupleCode`（アプリ内生成・同期キー） |
| 題材 | 旅程しおり（`trip:minamikyushu-2026` 等） | デートプラン管理 |

消えたとされるセクション（シルバーウィーク旅行 / バリ旅行 / 同棲計画 / やりたいことリスト）は、
構造上**教科書側（React 版）の旅程データ**に該当する可能性が高い。
React 版は公開されていないため、これらは実行時データではなく**未コミットのソース**として失われたと見られる。
